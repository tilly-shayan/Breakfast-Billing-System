# Breakfast Billing System
This is a simple console app that runs in a command-line interface. 
The user can pick items off the breakfast menu which adds each item, calculates the sales tax and finally provides a total bill.
# How It Works
Displays a menu with 8 breakfast items (eggs, bacon and egg, muffin, french toast, fruit basket, cereal, coffee, tea) with their price tags.
You can add items until you're satisfied with the order. Finaly, prints out a receipt breakdown that includes the subtotal, tax, and amount due.
### Executing program
Open a terminal in the project folder.
Then compile the program.
